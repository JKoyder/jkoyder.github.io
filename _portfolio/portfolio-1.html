--- title: "Machine Learning: Mountain Car using DQN" excerpt: "The PyTorch Mountain Car program is my attempt at solving Gymnasium’s Mountain Car problem using a Deep Q-Network in PyTorch. The program’s primary purpose is to train an AI agent to get up a hill in as few steps as possible. It does this by building up momentum and flinging itself up the steep hill, ultimately solving the problem. This project took careful consideration of hyperparameters, loss functions, and optimizer algorithms. While this implementation does not find the most efficient route to solving the problem, I was able to train the agent well enough to solve the problem consistently within the 200-step limit. The agent’s best reward was a -96, meaning that it solved the problem within 96 steps. A specific seed was used to obtain this result, however, using other seeds will produce similar results ranging from peak rewards of -100 to -140. A small DQN was used in this project as to not overcomplicate the data. There was similar reasoning used for the selection of optimizer and loss function. Huber loss allowed the agent to converge on a solution rather than falling into a local minima and optimizer Adam is an ideal algorithm for machine learning problems. This project demonstrates my strengths in software design, engineering, algorithms, and machine learning.
