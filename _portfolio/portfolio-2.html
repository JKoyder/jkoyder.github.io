--- title: "Grazioso Salvare Animal Database Application" excerpt: "The Grazioso Salvare Animal Database application is a full MEAN stack application that provides animal shelter data from the Austin, Texas area. The application’s primary purpose is to identify search and rescue animal candidates that are eligible for training. The application consists of a data table, filters, an animal by count graph, and an animal by count over time graph. When a user opens the single page application, data is fetched from the app API through an Express controller. The returned data is used to populate the Angular table and graphs. The data table incorporates sorting and pagination features so that users can easily traverse this data. The table filters can be used to filter the data by search and rescue/animal type. This similarly fetches data from the app API and updates the table and graphs. The data for this application is stored on a Mongo database which communicates with the app API through MongooseODM. This project demonstrates my strengths in software design, engineering, data structures, and databases.
